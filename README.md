
# Solar System Data — TS Academy HTML Milestone

A single-page HTML/CSS site exploring the solar system through data — built as a milestone assignment for TS Academy's frontend development track.

## About

This project recreates a Figma mockup using plain HTML and CSS, covering:

- Semantic page structure (`header`, `main`, `footer`, grouped sections)
- A muted, autoplaying, looping video
- An image with a `figure`/`figcaption` pairing
- A nested data table using `scope="rowgroup"`, `rowspan`, and `colspan` to group planets by type (Terrestrial, Jovian, Dwarf)
- Anchor links connecting the hero CTAs to the table and contact sections
- A fully validated contact form with labeled fields, grouped radio/checkbox inputs, and required-field constraints
